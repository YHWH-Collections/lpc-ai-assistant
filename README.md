# lpc-ai-assistant
AI-powered legal, privacy, compliance and governance assistant developed for Law, Privacy &amp; Compliance Ltd.


## Overview

The LPC AI Assistant provides conversational assistance relating to:

- Legal services
- Privacy and data protection
- UK GDPR
- Regulatory compliance
- Corporate governance
- AI governance
- Legal document signing and certification

## Features

- Conversational AI interface
- Responsive design
- Typing indicator
- Voice input
- Dynamic responses
- Mobile-friendly interface
- Integration with an AI API through a backend service

## Technology

- HTML5
- CSS3
- JavaScript
- PHP
- OpenRouter API

## Architecture

The frontend communicates with a PHP backend, which handles communication with the AI service.

Browser → PHP Backend → OpenRouter

## Security

API credentials and private configuration files are excluded from this repository.
